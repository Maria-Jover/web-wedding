# Imágenes

Coloca aquí la foto de portada con el nombre **`hero.jpg`**.

Recomendaciones:
- Formato apaisado (horizontal), mínimo 1920×1080 px.
- Foto luminosa, con la parte central despejada (el texto va encima).
- Peso ideal < 500 KB (comprímela en https://squoosh.app o https://tinyjpg.com).

Si no añades `hero.jpg`, la web muestra un degradado nude/salvia elegante como fondo.
